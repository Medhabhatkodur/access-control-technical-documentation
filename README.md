# Access-Control Technical Documentation Project

A practical technical documentation project demonstrating troubleshooting, system documentation, and AI-assisted content development.

## About the Project

This is a personal learning project created to practise turning technical information into clear, structured, and practical documentation.

The project focuses on an access-control scenario where a valid access card is detected but the door does not unlock.

This is a personal project and is not based on a real customer or production access-control system.

## What I Created

* **Troubleshooting Guide** – A structured guide for identifying common causes of an access-control door not unlocking.
* **Quick Reference** – A one-page reference for technicians to quickly follow the main troubleshooting checks.
* **System Overview** – A simple diagram showing how the access card, reader, controller, management software, and door lock interact.
* **AI-Assisted Documentation Workflow** – A simple workflow showing how AI can support the initial drafting process while human review and technical validation remain important.

## How I Used AI

I used AI as a support tool during the documentation process to help organise information, structure troubleshooting steps, and improve wording.

I reviewed and adjusted the generated content, checked the troubleshooting logic, and made the final decisions about what information should be included.

The purpose was to use AI to support the documentation workflow rather than replace human review and technical judgement.
